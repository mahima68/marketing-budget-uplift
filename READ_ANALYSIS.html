Marketing Budget Optimization Using Uplift Modelling

Decision: which 20% of an eligible audience should receive advertising? This is a noncommercial portfolio benchmark, not an estimate of Criteo's actual ROI. We compare purchase propensity with incremental response, select on validation data, and evaluate a frozen policy on an untouched test set. No deployment is required.

Learning path: read each explanation, run its cell, inspect the output, and explain what would change the business decision. The project uses real, corrected v2.1 data.

1. Source, sampling, and the limits of causal interpretation

Source: https://ailab.criteo.com/criteo-uplift-prediction-dataset/ Official publisher mirror: https://huggingface.co/datasets/criteo/criteo-uplift Use corrected v2.1, not the original release with advertiser leakage. The publisher anonymised features and non-uniformly subsampled data; estimates describe this released benchmark under a constant-assignment-probability assumption, not original advertiser effects. Assignment is eligibility to advertising, not guaranteed exposure. We take a seeded Bernoulli sample across the ENTIRE file, independent of all values. This retains natural outcome imbalance. We never take just the first rows.

2. Audit the data and prevent leakage

Only f0...f11 are inputs. visit and exposure are post-assignment variables: using them would reveal information unavailable when choosing whom to target. Feature labels have no business meaning; do not invent demographic descriptions. Identical feature vectors can occur after anonymisation; without user IDs they are not evidence of duplicated people, so we do not silently drop them.

5. Models: purchase probability versus incremental response

A propensity baseline predicts buying under treatment. A T-learner fits separate purchase models for treated/control users and subtracts probabilities. An S-learner fits one model with assignment as an input and predicts each user twice. We keep natural class frequencies: class weighting can distort probabilities needed for uplift. Complexity and the 20% capacity are fixed before final test inspection.

Show analysis code

6. Evaluate targeting policies, not individual counterfactual labels

We never observe both outcomes for one user. Use held-out doubly robust (DR) scores: phi = m1(X)-m0(X) + T/e*(Y-m1(X)) - (1-T)/(1-e)(Y-m0(X)). Nuisance outcome models are trained only on train; e is the train treatment fraction. For a target mask pi, mean(piphi) estimates additional conversions per eligible user versus targeting nobody. IPW gives a sensitivity check without outcome regression. Random targeting is evaluated as its expectation q*mean(phi), not a lucky random draw. Normal intervals and paired comparisons condition on fitted models; they do not include model-training uncertainty, hidden clustering, or dataset-selection uncertainty.

Show analysis code
def effect_scores(ix):
    m0=trees15[0].predict_proba(X[ix])[:,1];m1=trees15[1].predict_proba(X[ix])[:,1]
    ipw=t[ix]*y[ix]/e-(1-t[ix])*y[ix]/(1-e)
    dr=m1-m0+t[ix]*(y[ix]-m1)/e-(1-t[ix])*(y[ix]-m0)/(1-e)
    return dr,ipw

def policy(score,q):
    # Stable exact-size ranking, deterministic tie breaking independent of outcomes.
    k=int(np.floor(len(score)*q));mask=np.zeros(len(score));mask[np.argsort(-score,kind="stable")[:k]]=1
    return mask

def estimate(values):
    mu=float(np.mean(values));se=float(np.std(values,ddof=1)/np.sqrt(len(values)))
    return mu,mu-1.96*se,mu+1.96*se

vdr,vipw=effect_scores(va);vs=scores(X[va])

11. Write the decision memo from actual results

A positive estimate alone is insufficient to claim superiority. Paired uncertainty matters because policies are evaluated on the same users. Never describe benchmark estimates as realised revenue, observed savings, or proven individual causal effects.
